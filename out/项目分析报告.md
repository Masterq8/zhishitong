# 智审通 — 项目分析报告

## 一、项目概览

| 维度 | 数据 |
|------|------|
| 项目名称 | 智审通 — 面向高校行政事务的 Human-in-the-Loop 智能审批系统 |

## 二、技术架构

```
┌─────────────────────────────────────────────────────┐
│  表现层  │ React 18 + TypeScript + 玻璃拟态设计系统    │
│          │ 19 条路由, 7 核心组件, 5 角色差异化导航    │
├─────────────────────────────────────────────────────┤
│  服务层  │ FastAPI + SQLAlchemy + LangGraph           │
│          │ 14 个 Router, 11 个 Service, 分层架构      │
├─────────────────────────────────────────────────────┤
│  智能层  │ 云端 LLM (语义抽取) + 本地 Qwen3-14B       │
│          │ + OCR + RAG (TF-IDF) + 规则引擎兜底        │
├─────────────────────────────────────────────────────┤
│  数据层  │ 16 张核心表, SQLite, Redis 缓存            │
│          │ 用户/审批/通知/资源/日志/Key 池全链路       │
├─────────────────────────────────────────────────────┤
│  运维层  │ 健康检查 + 结构化日志 + Key 池故障转移      │
│          │ + 监控面板 + 一键启停脚本                   │
└─────────────────────────────────────────────────────┘
```

## 三、AI 能力图谱

| AI 能力 | 技术实现 | 模型/工具 | 部署位置 |
|---------|---------|----------|---------|
| 自然语言表单预填 | LLM 语义抽取 + 字段归一化 | 云端 LLM (DashScope) | 云端 |
| OCR 文档识别 | 多模态 LLM → EasyOCR 降级 | qwen-vl-max / EasyOCR | 云端 → 本地 |
| 政策检索 | TF-IDF 字符级 n-gram | scikit-learn + 自定义知识库 | 本地 |
| 合规分析 | RAG + LLM 生成 | 本地 Qwen3-14B (llama.cpp) | 本地 |
| 意图分类 | 云端 LLM 分类 → 规则兜底 | 云端 LLM | 云端 |
| 相似案例检索 | 历史审批记录匹配 | SQL + TF-IDF | 本地 |
| 政策问答 ChatBot | 多轮对话 + 引用来源 | 本地 Qwen3-14B | 本地 |
| 预审规则引擎 | 硬性规则检查（必填/范围/查重） | Python 规则引擎 | 本地 |
| LoRA 微调 | MLX 训练 → 融合 → GGUF 转换 | Qwen3-14B | 本地/GPU |

## 四、Human-in-the-Loop 设计

```
学生提交 ──→ AI 辅助层 ──→ 人工审批 ──→ 通知归档
  │              │              │
  │         · OCR 提取      · 合规分析面板
  │         · 字段预填      · 风险高亮
  │         · 合规自查      · 意见草稿
  │         · 政策引用      · 相似案例
  │              │              │
  └──── AI 全程辅助，人保留最终决策权 ────┘
```
